# Security Policy

## Melaporkan kerentanan

Jangan mempublikasikan detail keamanan yang dapat dieksploitasi melalui issue publik.

Gunakan fitur private vulnerability reporting GitHub untuk repository ini apabila tersedia. Jika fitur tersebut tidak tersedia, hubungi maintainer repository melalui GitHub dan sertakan deskripsi singkat, revisi yang terdampak, dampak, serta langkah reproduksi yang aman.

## Cakupan

Aplikasi saat ini hanya berupa kerangka Android dasar. Aplikasi belum menjalankan perintah privileged dan belum berinteraksi dengan interface kernel. Laporan terkait pipeline build, konfigurasi repository, atau kode startup tetap dapat diajukan.
